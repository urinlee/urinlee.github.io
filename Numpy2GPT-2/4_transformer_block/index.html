posted by 지티오,

앞 글에서는 Multi-Head Masked Self-Attention까지 구현했다. 전체 순전파를 조립하기 전에, 블록을 구성하는 나머지 연산인 LayerNorm, 잔차 연결, FFN의 원리와 코드를 정리한다.

1. LayerNorm

LayerNorm은 입력을 정규화하기 위해 사용한다. 입력 x의 크기가 (seq_len, 768)이라면, 토큰 하나를 나타내는 각 행의 768개 성분 안에서 평균과 분산을 계산한다.

x^i=xi−μσ2+ϵ

μ는 해당 토큰 벡터의 평균, σ²는 분산이다. 평균을 빼서 중심을 0으로 옮기고, 표준편차로 나눠 값이 퍼진 정도를 조절한다. ϵ는 분산이 0이거나 아주 작을 때도 나눗셈을 안정적으로 계산하기 위한 작은 값이다.

이렇게 하면 벡터의 전체적인 크기와 평균을 정돈해, 다음 층이 입력 스케일의 변화에 지나치게 영향받지 않도록 돕는다. 다른 토큰과 평균을 내는 연산은 아니다.

GPT-2의 LayerNorm은 여기서 끝나지 않고, 정규화한 값에 학습 가능한 γ를 곱하고 β를 더한다.

LayerNorm(x)i=γix^i+βi

γ와 β의 크기는 각각 (768,)이고, 같은 LayerNorm을 지나는 모든 토큰이 공유한다. 평균과 분산은 입력마다 다시 계산하지만, γ와 β는 학습 파라미터다. 따라서 최종 출력의 평균과 분산이 항상 0과 1인 것은 아니다.

import numpy as np

def layer_norm(x, gamma, beta, eps=1e-5):
    mean = np.mean(x, axis=-1, keepdims=True)
    var = np.var(x, axis=-1, keepdims=True)

    normalized = (x - mean) / np.sqrt(var + eps)
    return gamma * normalized + beta


# x: 앞 단계에서 만든 (seq_len, d_model) 입력
d_model = x.shape[-1]
gamma_1 = np.ones(d_model)
beta_1 = np.zeros(d_model)

x_norm = layer_norm(x, gamma_1, beta_1)

axis=-1로 마지막 차원인 벡터 성분 방향을 계산한다. keepdims=True를 쓰면 평균과 분산의 크기가 (seq_len, 1)로 유지돼 각 행에 맞춰 뺄셈과 나눗셈이 적용된다. np.var는 기본값인 ddof=0을 사용한다.

2. 잔차연결

y=x+F(x)

잔차 연결은 계산 결과 F(x)와 원래 입력 x를 더하는 것이다. 입력을 그대로 전달하는 것이 유리한 상황에서도, 매번 새로운 변환만 거치게 되면 필요한 표현이 달라질 수 있다. 잔차 연결은 입력이 직접 전달되는 경로를 두고, 그 위에 계산한 변화를 더하도록 한다.

F(x)가 0에 가까우면 입력이 거의 그대로 전달된다. 다만 원래 입력이 별도로 저장되는 것은 아니며, 더한 결과도 입력과 달라질 수 있다.

예시

사진의 밝기만 조금 높이는 상황에 비유할 수 있다.

  • 잔차 연결 없음: 모델이 보정된 사진 전체를 만들어야 하므로, 밝기를 바꾸려다 원래 모습까지 달라질 수 있다.
  • 잔차 연결 있음: 원본 사진을 직접 전달하고 밝기 보정량만 더하도록 학습할 수 있다.

GPT-2에서는 LayerNorm을 거친 입력으로 Attention을 계산하고, 그 결과를 정규화하기 전의 입력 x에 더한다.

h=x+Attention(LayerNorm1(x)) 
# output: x_norm으로 Q, K, V부터 계산한 어텐션 출력
# x는 정규화하기 전의 입력으로 유지한다.
assert x.shape == output.shape
h = x + output

입력과 출력 크기를 확인하는 것은 NumPy의 브로드캐스팅으로 의도와 다른 덧셈이 일어나는 것을 막기 위해서다. 잔차 연결 자체에는 별도의 학습 파라미터가 없다.

입력에서 출력으로 직접 이어지는 경로는 역전파 때 기울기가 전달될 경로도 제공하므로, 깊은 모델의 학습을 돕는다.

3. FFN

FFN은 토큰 벡터의 성분들을 조합하고 비선형적으로 변환한다. Attention이 토큰 사이에서 정보를 가져왔다면, FFN은 그 정보가 반영된 각 토큰 벡터를 가공한다. 모든 토큰에 같은 가중치를 적용하지만, FFN 내부에서 토큰끼리 직접 정보를 섞지는 않는다.

FFN(z)=GELU(zW1+b1)W2+b2

여기서 z는 두 번째 LayerNorm을 통과한 FFN 입력이다. GPT-2 small을 기준으로 계산 순서와 차원은 다음과 같다.

z=LayerNorm2(h)

앞선 잔차 연결의 결과 h를 정규화해 FFN의 입력 z를 만든다.

a=zW1+b1

가중치 W₁과 편향 b₁로 입력 성분을 조합해, 768차원을 3072차원으로 넓힌다.

u=GELU(a)

각 성분에 GELU를 적용해 비선형으로 변환한다. 차원은 3072로 유지된다.

FFN(z)=uW2+b2

가중치 W₂와 편향 b₂로 중간 특징을 다시 조합해, 원래의 768차원으로 돌려놓는다.

단계 벡터 크기 하는 일
입력 z (seq_len, 768) 토큰별 입력 벡터
첫 번째 선형 변환 a (seq_len, 3072) 성분들을 조합해 차원 확장
GELU 적용 u (seq_len, 3072) 비선형 변환
두 번째 선형 변환 (seq_len, 768) 원래 차원으로 변환

3072차원으로 늘리는 것은 입력을 네 번 복사하는 것이 아니다. 서로 다른 가중치로 입력 성분을 조합해 더 많은 중간 특징을 만들고, 마지막 변환에서 다시 768차원으로 모은다.

중간에 적용하는 GELU의 GPT-2 근사식은 다음과 같다.

GELU(t)≈t2[1+tanh(2π(t+0.044715t3))]

GELU는 큰 양수는 거의 그대로 통과시키고, 큰 음수는 0에 가깝게 만든다. 0 근처에서는 부드럽게 변하며, 음수를 모두 정확히 0으로 만드는 함수는 아니다.

이 함수를 중간에 넣는 이유는 선형 변환만 반복하면 하나의 선형 변환으로 합쳐지기 때문이다.

(zW1)W2=z(W1W2)

편향이 있어도 하나의 선형 변환과 편향으로 묶을 수 있다. GELU로 비선형성을 추가해야 입력에 따라 달라지는 더 복잡한 변환을 표현할 수 있다.

def gelu(x):
    return 0.5 * x * (
        1 + np.tanh(
            np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)
        )
    )


d_model = h.shape[-1]
d_ff = 4 * d_model
rng = np.random.default_rng(42)

W_1 = rng.normal(0, 0.02, size=(d_model, d_ff))
b_1 = np.zeros(d_ff)
W_2 = rng.normal(0, 0.02, size=(d_ff, d_model))
b_2 = np.zeros(d_model)

# 두 번째 LayerNorm은 별도의 gamma, beta를 사용한다.
gamma_2 = np.ones(d_model)
beta_2 = np.zeros(d_model)
h_norm = layer_norm(h, gamma_2, beta_2)

ffn_hidden = h_norm @ W_1 + b_1
ffn_activated = gelu(ffn_hidden)
ffn_output = ffn_activated @ W_2 + b_2

# FFN 결과도 정규화하기 전의 입력에 더한다.
assert h.shape == ffn_output.shape
y = h + ffn_output

코드의 FFN 가중치는 학습 전의 무작위 값이다. h → 두 번째 LayerNorm → FFN으로 계산한 결과를 다시 h에 더하면 블록의 두 번째 잔차 연결까지 이어진다.

4. 결합

이제 앞에서 만든 연산을 연결할 차례다. GPT-2의 구조를 정하는 설정은 Hugging Face의 config.json에 있었다. 여기서는 이 저장소의 GPT-2 small을 기준으로 조립한다.

4.1. GPT-2의 헤드 구조

설정의 n_embd는 768, n_head는 12다. 따라서 Q·K·V를 각각 12개의 헤드로 나누면, 헤드 하나가 다루는 차원은 768 / 12 = 64가 된다.

각 헤드가 계산한 결과는 이어 붙여 다시 768차원으로 만든다. 이 과정은 앞 글의 Multi-head self-attention 구현에서 정리했다.

4.2. GPT-2의 블록 구조

블록 내부의 연산 순서는 GPT-2 원본 구현의 block()에서 확인했다. GPT-2는 Attention과 FFN 앞에 LayerNorm을 적용하며, 각 계산 결과에 정규화하기 전의 입력을 더한다.

입력 x
  ↓
LayerNorm ①
  ↓
Masked Multi-Head Attention
  ↓
원래 입력 x와 더하기 → h
  ↓
LayerNorm ②
  ↓
FFN: 768 → 3072 → GELU → 768
  ↓
FFN에 들어가기 전의 h와 더하기 → 블록 출력

토큰 수가 seq_len이라면 블록의 입력과 출력은 모두 (seq_len, 768)이다. FFN에서 중간 차원을 넓혔다가 다시 768차원으로 돌려놓기 때문에 잔차 연결을 이어갈 수 있다.

4.3. GPT-2의 블록 개수

n_layer는 12다. 위 구조의 블록을 12개 쌓고, 앞 블록의 출력을 다음 블록의 입력으로 전달한다. 블록의 계산 구조는 같지만 가중치는 블록마다 따로 가진다.

즉, 12개 블록 각각의 Attention 안에 12개 헤드가 있다.

4.4. 전체적인 구조

토큰 임베딩과 위치 임베딩을 더한 입력에서 시작해, 12개 블록을 통과한 뒤 마지막 LayerNorm과 어휘 출력층을 연결한다.

토큰 ID
  ↓
토큰 임베딩 + 위치 임베딩
  ↓
Transformer 블록 × 12
  ↓
마지막 LayerNorm
  ↓
토큰 임베딩 표의 전치와 곱하기
  ↓
logits: (seq_len, 50257)
  ↓
Softmax → 다음 토큰의 확률

출력층은 입력에 사용한 토큰 임베딩 표를 공유한다. 각 위치의 logits은 그 위치 다음에 올 토큰의 점수다. 전체 흐름은 원본 구현의 model()에서도 확인할 수 있다.

4.5. 순전파를 구성하는 핵심 함수

조립한 코드의 핵심 함수는 다음과 같다. 여기서는 함수의 역할과 입출력만 정리하고, 내부 계산은 앞에서 설명한 부분으로 연결한다. 아래 타입 표기는 함수의 입출력을 보여주기 위해 덧붙였다.

공통으로 x는 NumPy 배열, weights는 가중치 딕셔너리, config는 모델 설정이다. prefix와 layer_index는 사용할 가중치의 위치를 지정한다. return_trace 인자가 있는 함수는 이를 True로 설정하면 중간 계산값도 함께 반환한다. 기본값에서는 중간값 대신 None을 반환한다.

layer_norm() — 토큰별 정규화

def layer_norm(
    x: np.ndarray,
    gamma: np.ndarray,
    beta: np.ndarray,
    eps: float = 1e-5,
) -> np.ndarray:
    ...

각 토큰 벡터를 정규화하고 gamma, beta를 적용한 배열을 반환한다. 입력과 출력의 크기는 같다. 원리와 코드는 이 글의 1. LayerNorm에 정리했다.

softmax() — 점수를 확률로 변환

def softmax(x: np.ndarray) -> np.ndarray:
    ...

마지막 차원의 점수를 합이 1인 확률로 바꿔 반환한다. Attention의 참고 비율과 마지막 어휘별 확률을 구할 때 사용한다. 계산은 앞 글의 Softmax로 참고 비율 구하기, 출력층에서의 역할은 1편의 확률로 만들기에 설명했다.

masked_self_attention() — 앞의 토큰 정보를 모으기

def masked_self_attention(
    x: np.ndarray,
    weights: dict,
    prefix: str,
    num_heads: int,
    return_trace: bool = False,
) -> tuple[np.ndarray, dict | None]:
    ...

Q·K·V 계산부터 미래 토큰 마스킹, 헤드 결합과 출력 투영까지 수행한다. (어텐션 출력, 중간 계산값)을 반환하며, 출력 크기는 입력과 같다. 세부 연산은 앞 글의 Multi-head self-attention 구현에 있다.

gelu() — 비선형 변환

def gelu(x: np.ndarray) -> np.ndarray:
    ...

배열의 각 성분에 GPT-2의 GELU 근사식을 적용한 결과를 반환한다. 배열의 크기는 유지된다. 수식과 그래프는 이 글의 3. FFN에 정리했다.

feed_forward() — 토큰 안의 특징 가공

def feed_forward(
    x: np.ndarray,
    weights: dict,
    prefix: str,
    return_trace: bool = False,
) -> tuple[np.ndarray, dict | None]:
    ...

차원 확장, GELU, 차원 축소를 연결해 (FFN 출력, 중간 계산값)을 반환한다. 각 토큰에 같은 연산을 적용하며 출력은 다시 768차원이다. 계산 순서는 이 글의 3. FFN에 있다.

transformer_block() — 블록 하나 조립

def transformer_block(
    x: np.ndarray,
    weights: dict,
    config: GPT2Config,
    layer_index: int,
    return_trace: bool = False,
) -> tuple[np.ndarray, dict | None]:
    ...

두 번의 LayerNorm, Attention, FFN과 두 잔차 연결을 묶어 (블록 출력, 중간 계산값)을 반환한다. 잔차 연결은 이 글의 2. 잔차연결, 조립 순서는 4.2. 블록 구조를 따른다.

forward() — 전체 순전파 연결

def forward(
    token_ids: np.ndarray,
    weights: dict,
    config: GPT2Config,
    return_trace: bool = False,
) -> dict:
    ...

토큰 ID에서 시작해 임베딩, 12개 블록, 마지막 LayerNorm, 출력층과 Softmax를 연결한다. logits, probabilities, 마지막 LayerNorm의 출력인 hidden_state, 중간 계산값인 trace를 담은 딕셔너리를 반환한다. trace는 기본값에서 None이다.

입력 구성은 2편의 임베딩 결합 구현, 출력 점수와 확률은 1편의 logits 출력과 Softmax를 연결한 것이다.

수식과 연산 순서는 GPT-2 원본 구현의 norm, block, mlp, gelu를 참고했다.
