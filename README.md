# 블로그 글 작성

## 논문 카드

글 본문에서 코드 블록의 언어를 `paper`로 지정하면 논문 카드로 표시됩니다.
왼쪽에는 기관 로고와 이름, 오른쪽에는 제목·설명·저자·발행 정보를 보여주며 카드 전체를 누르면 원문이 새 탭에서 열립니다.
오른쪽 배경에는 흐릿한 영문 논문 지면을 사용합니다. 배경은 장식용이며, 논문 정보는 `paper` 블록에서 가져옵니다.
모바일에서는 기관 정보를 위쪽에 배치해 긴 논문 제목을 넓게 표시합니다.

````markdown
```paper
title: The Illusion of Thinking
institution: Apple
logo: /paper-logos/apple.ico
authors: Parshin Shojaee et al.
year: 2025
venue: NeurIPS
url: https://arxiv.org/abs/2506.06941
summary: 문제 복잡도에 따라 달라지는 추론 모델의 강점과 한계를 살펴본 연구.
```
````

- `title`, `institution`, `url`은 필수입니다. 나머지 항목은 필요한 것만 넣으세요.
- 다른 기관 로고는 `static/paper-logos/`에 저장하고 `logo: /paper-logos/파일명.svg`처럼 적으세요. 외부 `https` 이미지 주소도 사용할 수 있습니다. 로고를 생략하면 문서 아이콘을 표시합니다.
- 설명이 길면 YAML의 `summary: >-` 다음 줄부터 두 칸 들여써서 여러 줄로 작성할 수 있습니다. `: `가 들어간 제목은 따옴표로 감싸세요.
- 여러 논문은 `paper` 블록을 각각 추가하면 됩니다. 모바일과 다크 모드에 자동으로 맞춰집니다.
- 잘못된 필수 정보나 주소는 빌드 중 파일명과 줄 번호로 알려줍니다.

실제 논문을 사용한 [작성 예시](examples/paper-card.md)도 참고하세요.

## 형광펜

`content/글주소/index.md`에서 강조할 문장을 `==`로 감싸세요. 색을 생략하면 노랑입니다.

```markdown
==중요한 문장==
==yellow:노랑 형광펜==
==green:초록 형광펜==
==blue:파랑 형광펜==
==pink:분홍 형광펜==
==orange:주황 형광펜==
==purple:보라 형광펜==
==red:빨강 형광펜==
==teal:청록 형광펜==
==skyblue:하늘색 형광펜==
==gray:회색 형광펜==
==#FFCC80:원하는 HEX 색상==
==#9CF:짧은 HEX 색상==
```

- `red`, `teal`, `gray`, `rebeccapurple` 등 CSS 색상 이름도 사용할 수 있습니다. 대소문자는 구분하지 않습니다.
- 자주 쓰는 색 이름은 `yellow`(노랑), `blue`(파랑), `green`(초록), `orange`(주황), `red`(빨강), `pink`(분홍), `purple`(보라), `teal`(청록), `skyblue`(하늘색), `gray`(회색)입니다. “초록으로 강조”처럼 요청하면 해당 영문 키워드로 작성하면 됩니다.
- HEX 코드는 `#RGB` 또는 `#RRGGBB` 형식으로 적습니다.
- 색상은 밝은 화면과 다크 모드에서 읽기 좋도록 연하게 조정됩니다.
- 같은 소스 줄 안에서 `==`를 열고 닫으세요. 화면 폭에 따른 줄바꿈은 자동으로 처리됩니다.
- 여러 강조 구간 사이에는 공백이나 문장부호를 넣으세요.

굵게 쓰기, 소제목, 인용문과 함께 사용할 수도 있습니다.

```markdown
==green:**굵게 강조할 문장**==

### 두 번째, ==green:신뢰==

> 나에게 신뢰란, ==green:태도와 행동으로 쌓이는 믿음==이다.
```

문법을 그대로 보여주려면 인라인 코드나 코드 블록에 넣으세요. 일반 문장에서는 여는 기호 앞에 역슬래시를 붙여 `\==문장==`처럼 적어도 됩니다.

## 밑줄

형광펜 없이 글자 아래에 선만 넣으려면 `++문장++`으로 감싸세요.
색상·선 모양·굵기를 쉼표로 조합할 수 있습니다. 순서는 자유롭고, 생략하면 글자색의 보통 굵기 실선을 사용합니다.

```markdown
++기본 밑줄++
++solid:실선 밑줄++
++wavy:물결 밑줄++
++dashed:끊어진 파선 밑줄++
++dotted:점선 밑줄++
++double:이중 밑줄++
++blue,wavy:파란 물결 밑줄++
++red,dashed,thick:굵은 빨간 파선 밑줄++
++#9CF,double,thin:가는 하늘색 이중 밑줄++
++**굵은 글자에도 밑줄**++
```

| 설정    | 사용할 수 있는 값                                                                                  |
| ------- | -------------------------------------------------------------------------------------------------- |
| 선 모양 | `solid` (실선 `_`), `wavy` (물결 `~`), `dashed` (파선 `- - -`), `dotted` (점선), `double` (이중선) |
| 굵기    | `thin` (1px), `regular` (1.5px, 기본), `thick` (3px)                                               |
| 색상    | `blue`, `red` 같은 CSS 색상 이름 또는 `#RGB`, `#RRGGBB`                                            |

글자색은 그대로 유지하고 밑줄 색상만 바뀝니다. 밝은 화면·다크 모드에서 선이 보이도록 색상을 조정하며, 화면 폭에 따라 줄이 바뀌어도 밑줄이 이어집니다.
일반 굵게 쓰기(`**문장**`)와 형광펜(`==문장==`) 문법은 그대로 사용할 수 있습니다.
문법 자체를 보여주려면 코드로 감싸거나 `\++문장++`처럼 여는 기호 앞에 역슬래시를 붙이세요.

## 넉넉한 문단 간격

형광펜은 모든 게시글에서 사용할 수 있습니다. 현재 자기소개 글처럼 문단과 인용문 간격도 넓히고 싶다면 글 상단의 메타데이터에 다음 줄을 추가하세요.

```yaml
readingStyle: reflection
```
